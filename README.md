# 🪄 WARDROBE
Примерочная для CatWar, облегчающая процесс подбора скинов.

## Где найти?
Выглядит как свёрнутая трея.<br>
Вкладка кролей — прямо над списком пропускных костюмов.<br>
Настройки костюмов — под настройкой костюмов.


## Как пользоваться?
- Костюмы со страницы — всё что есть на текущей странице отображается в списке справа от предпросмотра. При клике надевается. ВНИМАНИЕ! Не надетые костюмы в выборе костюмов не смогут отобразиться в списке.
- Поиск по ID — развернув раздел «Поиск костюмов», можно вбить ID вручную или нажать одну из быстрых кнопок с категориями (на данный момент только пропуски). Список поиска листается стрелками влево/вправо.
- Слои — костюмы накладываются друг на друга. В панели слоёв можно менять порядок перетаскиванием и удалять лишнее крестиком.
- Своя модель/костюм — можно заменить вашего персонажа на любой скин: нужно вставить URL или загрузить файл. Кнопка «вернуть оригинал» возвращает исходный окрас.
- Тёмная / светлая тема — кнопка ☀ / ☾ в шапке панели.
